# Production Dependency Security

Updated: 2026-10-01

The production hardening wave uses a lockfile-only npm remediation generated by the repository's CI runner.

- Direct Expo / React Native versions remain on the established Expo 52 baseline.
- `npm audit fix --package-lock-only --ignore-scripts` reduced the audited npm dependency set to zero reported vulnerabilities in the generated candidate.
- No `package.json` dependency upgrade to the Expo 57 line is used as a shortcut.
- The dependency gate remains release-blocking for high/critical findings.
- Future major Expo modernization is tracked separately from security remediation.

This document records the security remediation boundary; it does not constitute a regulatory or clinical approval.
