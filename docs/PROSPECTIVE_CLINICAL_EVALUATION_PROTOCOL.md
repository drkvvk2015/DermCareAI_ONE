# DermCareAI Prospective Clinical Evaluation Protocol

**Status:** Protocol package ready — prospective execution and accountable clinical approval are required

## Objective

Evaluate DermCareAI as clinician decision support in the intended dermatology workflow under controlled prospective use without allowing the software to silently replace clinician judgment.

## Core safeguards

- Clinician remains accountable for the clinical decision.
- AI output remains advisory and auditable.
- Patient consent and institutional governance must be established before study activation.
- The study version, model version and software version are frozen for the defined evaluation period.
- Protocol deviations are logged and reviewed.
- Patient-identifying study data remain in the approved clinical environment and are not committed to Git.

## Pre-activation checklist

- [ ] Institution/site identified
- [ ] Responsible investigator identified
- [ ] Appropriate ethics/institutional review completed where applicable
- [ ] Consent/notice process approved
- [ ] Intended use and exclusion criteria frozen
- [ ] Model and software versions frozen
- [ ] Training completed for participating clinicians
- [ ] Safety escalation pathway documented
- [ ] Data protection/retention plan approved
- [ ] Statistical analysis plan signed
- [ ] Independent monitoring/review responsibility assigned

## Prospective endpoints

Define before activation:

- workflow feasibility;
- clinician acceptance/rejection/override patterns;
- abstention frequency;
- clinically significant discordance;
- turnaround time;
- safety events and near misses;
- protocol deviations;
- data-quality failures;
- usability and human-factors observations relevant to safe use.

Any clinical performance endpoint must use a pre-specified reference standard and analysis plan.

## Safety monitoring

Define:

- event classification;
- immediate escalation route;
- temporary suspension criteria;
- model/software rollback procedure;
- incident documentation;
- periodic safety review.

## End-of-study package

Produce:

- protocol and approved amendments;
- denominator/accounting flow;
- endpoint analysis;
- protocol deviations;
- safety events/near misses;
- subgroup findings where appropriate;
- clinician override analysis;
- version hashes;
- independent review/sign-off.

This package is an operational protocol. It is not evidence that a prospective study has already been conducted.
